# Captured 2026-05-21 17:13 UTC after ~7 minutes of continuous traffic-gen.
# Notes:
#  - All connections show connection_security_policy="mutual_tls" — ztunnel is
#    transparently wrapping every L4 connection in mTLS without any sidecar
#    in the application pods (which are 1/1, not 2/2 as in classic Istio).
#  - source_principal and destination_principal are SPIFFE identities
#    derived from each pod's Kubernetes ServiceAccount, not from IP/DNS.
#    AuthorizationPolicy can target these identities directly.
#  - reporter=source means the metric was emitted by the originating ztunnel;
#    reporter=destination means it was emitted by the receiving ztunnel.
#    Both report the same connection — gives Kiali bidirectional visibility.
